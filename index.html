Projects

3D Engine CPU Rasterizer C, SDL2

An interactive 3D engine in C with no GPU API, using SDL2 for windowing and input. It does backface culling, near-plane clipping, dynamic camera transforms with six degrees of freedom, and basic lighting. Four render modes (wireframe, vertex-highlighted, solid fill, textured) switch from the keyboard, and the code is split into lighting, geometry, mesh, culling, and camera modules.

Sulfur Events Lottery App Java, Firebase

A full-stack Android app for managing events and their sign-up lotteries, built with a team in Java and Android Studio. I implemented QR code generation and scanning, including storing and reading embedded geolocation to show and update event and user locations. Cloud Firestore handles storage, queries, and consistency across users.

RISC-V to WASM Converter RISC-V (RV32I)

Converts RV32I machine code to WebAssembly bytecode, supporting R-type, I-type, and branch instructions: arithmetic, logic, shifts, and conditional control flow. I built a signed LEB128 encoder from scratch to emit immediate operands. Course project, so the code is private; I'm happy to walk through it.

Distributed System Monitor C++

Two programs, distpsnotify and remoteagent, that collect real-time data from several remote machines at once over TCP/IP. They speak a custom client-server protocol (EXECUTE/QUIT, START/STOP delimiters) over persistent connections. Agent state is heap-allocated for any number of machines, with zero leaks on every code path, verified with Clang's leak tools on macOS. Course project.

Consistant Swift, Supabase

A native iOS habit tracker built with SwiftUI and Supabase/Postgres, with row-level security and offline-first sync. It's an experiment in agentic development: I directed AI agents through the code generation and wrote the system architecture specifications myself.
